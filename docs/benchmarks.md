# 벤치마크 기록 (F6·F7 pose 모델)

담당 A. 목적:
1. Hailo-8L에서 쓸 pose 모델 선택 ([decisions.md](decisions.md) D-010: 초당 10프레임 이상 중 누운 자세 인식이 가장 좋은 모델).
2. **가속기(AI HAT+) 필요성 근거**: 같은 모델을 Pi 5 CPU와 Hailo에서 돌린 결과를 나란히 비교한다.
   (운영은 Hailo로 확정(D-009). CPU는 비교 기준으로만 측정.)

측정값은 실제로 잰 것만 적는다. 추정·인터넷 수치는 쓰지 말고, 참고하면 출처를 따로 적는다.

## 측정 방법
속도·자원 표는 `python -m pi.scripts.bench_pose --hef <파일>`이 출력하는 줄을 그대로 붙인다 (명령: [setup.md](setup.md) 2-3-2).
전력(W)만 USB 전력계로 따로 재서 적는다. CPU 비교 측정 스크립트는 아직 없음 (TODO).
- **FPS**: 카메라 캡처 → 전처리 → 추론 → 후처리(키포인트)까지 전체 파이프라인, 60초 평균. 추론만 따로도 기록.
- **지연**: 프레임 1장 기준 캡처~키포인트 결과까지 ms (중앙값, p95).
- **누운 자세 인식**: 아래 테스트 세트에서 사람 검출 성공률과 주요 키포인트(머리·어깨·엉덩이) 신뢰도 ≥ 임계값 비율.
- **전력·발열**: 10분 연속 실행 중 `vcgencmd measure_temp`, `vcgencmd get_throttled`. 가능하면 USB 전력계 W.
- 모든 측정은 프레임을 메모리에서만 처리하고 저장하지 않는다 (영상 저장 금지). 테스트 세트도 동의한 팀원이 직접 연기한 장면을 **실시간**으로 측정하고, 결과 숫자만 기록한다.
