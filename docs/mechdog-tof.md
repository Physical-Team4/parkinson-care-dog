# MechDog 뒤 ToF 거리 센서 (VL53L1X) 작업 노트

작업하면서 직접 부딪히고 알아낸 내용과 주의사항을 정리한 문서입니다.
코드 파일: `esp32/mainboard.py` (보드에는 `main.py`로 올림), `esp32/Tof_test.py`
리듬 큐잉·MP3·걷기·업로드 내용은 [mechdog-rhythm.md](mechdog-rhythm.md) 참고.

---

## 1. 기능 요약

| 기능 | 동작 |
|---|---|
| 뒤 장애물 멈춤 | 리듬 큐잉이 아닐 때, 뒤 20cm 안에 물체가 있으면 뒤로 걷기를 멈춤 |
| 사람 따라오기 | 리듬 큐잉 중, 뒤 사람과의 거리에 따라 보폭 조절 / 놓치면 멈춰서 대기 |

## 2. 눈(LED) 색깔 의미

눈은 앞쪽 초음파 센서의 LED를 사용함.

### 리듬 큐잉 중

| 상황 | 눈 | 동작 |
|---|---|---|
| 시작 직후, 뒤에 사람 없음 | 주황 깜빡임 | 제자리에서 대기 (박수는 계속) |
| 사람이 1.5m 안에 0.7초 이상 잡힘 | 초록 | 걷기 시작 |
| 사람이 50cm 이내 | 초록 | 원래 보폭으로 걷기 |
| 사람이 50cm ~ 1.2m | 초록 | 멀어질수록 보폭을 줄여 천천히 걷기 |
| 1.5m보다 멀거나 안 잡힘이 1초 이상 | 주황 깜빡임 | 멈춰서 기다림 |
| 10초 이상 계속 못 찾음 | 꺼짐 | 리듬 큐잉 종료 |
| 터치로 정지 | 꺼짐 | 멈추고 기본 자세 |

### 리듬 큐잉이 아닐 때

| 상황 | 눈 |
|---|---|
| 뒤 20cm 안에 물체 있음 | 빨강 (뒤로 걷기 막힘) |
| 뒤 물체가 사라짐 | 꺼짐 |

## 3. 포트와 I2C 통로 번호

**보드에 적힌 포트 번호와 코드의 통로 번호(`IIC(1)`, `IIC(2)`)는 다를 수 있음.** 헷갈리면 항상 `scan()`으로 확인할 것.

```python
import Hiwonder_IIC
print("bus1:", Hiwonder_IIC.IIC(1).scan())
print("bus2:", Hiwonder_IIC.IIC(2).scan())
```

| 장치 | 주소 | 확인된 통로 | 비고 |
|---|---|---|---|
| 자세 센서(IMU, 보드 내장) | 106 (0x6A) | 1 | 항상 보임 |
| 앞 초음파 센서(눈) | 119 (0x77) | 1 | 항상 보임 |
| 뒤 ToF 센서 VL53L1X | 41 (0x29) | 1 | 코드는 1, 2번 통로 자동 탐색 |
| WonderEcho 음성 모듈 | 52 (0x34) | 2 | 보드 1번 포트에 꽂았을 때 |
| MP3 모듈 | - | 블록에서 "포트 2" | scan에 잘 안 잡힘, 코드는 자동 탐색 |
| 터치 센서 | - | 3번 포트 (IO33) | I2C 아님, 여기에 I2C 장치 꽂지 말 것 |

- `OSError: [Errno 19] ENODEV` = 그 주소에 장치가 없다는 뜻. 연결이 빠졌거나, 다른 장치 주소로 명령을 보내고 있는 것
- 검사(`scan`)가 끝나지 않고 멈추면 통신선이 꼬였거나(SDA/SCL), 전원이 안 들어간 장치가 선을 붙잡고 있는 것

## 4. 뒤 ToF 거리 센서 (VL53L1X, CJMCU-531) 주의사항

### 연결

- 6핀 중 **VCC, GND, SCL, SDA 4개만** 연결. GPIO1, XSHUT은 비워둠
- 기판에 전압 조절 칩과 저항이 있어서 **MechDog 포트의 5V를 그대로 연결해도 됨**
- **선 색깔을 믿지 말 것.** 연결 케이블의 빨간 선이 VCC가 아닐 수 있음. 반드시 포트 핀 순서와 센서 글자를 이름끼리 맞출 것
- VCC와 GND가 바뀌면 센서가 망가질 수 있음. 전원 켜기 전에 한 번 더 확인
- 연결 정보 (작업 후 채워 넣기): 포트 ___번 / VCC = ___색, GND = ___색, SCL = ___색, SDA = ___색

### 납땜

- **납땜 없이 헤더핀만 꽂으면 접촉이 안 됨.** 실제로 납땜 전에는 센서가 전혀 안 잡혔음
- 헤더핀 방향: **짧은 쪽을 센서 없는 면(뒷면)에서 꽂아 넣고**, 플라스틱 받침이 뒷면에 닿게 함. 긴 쪽이 뒷면으로 나와 점퍼선을 꽂음
- 납땜은 센서 창이 있는 면으로 살짝(약 1mm) 튀어나온 핀 끝에서 함
- 인두를 핀과 구멍 둘레 금속 테두리에 동시에 대고 2~3초 안에 끝내기
- 잘된 납땜은 반짝이는 원뿔 모양. 동그란 공처럼 맺히면 다시 데우기
- **모든 핀이 납땜됐는지 확인할 것.** 실제로 GND 하나가 빠져서 센서가 안 켜졌었음
- 옆 핀끼리 납이 이어지지 않게 주의 (특히 VCC-GND)
- 납땜 중 센서가 뜨거워지는 건 정상. **전원을 켰을 때 뜨거워지면 즉시 전원을 끄고** 연결 확인

### 보호 필름

- 납땜할 때는 센서 창 보호 필름을 붙여두고 (연기, 송진 방지)
- **납땜이 끝나면 반드시 필름을 뗄 것.** 필름이 있으면 레이저가 반사돼서 아무것도 없어도 가까운 물체가 있는 것처럼 측정됨 (실제로 이것 때문에 뒤로 걷기가 계속 막혔음)
- 센서 창에 송진이 묻었으면 면봉에 소독용 알코올을 살짝 묻혀 닦기

### 테스트

- `Tof_test.py`를 올리면 센서를 찾고 30초 동안 거리를 0.2초마다 출력함
- 정상 결과 예: `bus 1 devices: [41, 106, 119]` → `ToF OK on bus 1 access mode: mem16` → `distance: 225 mm`
- 측정 범위 약 5mm ~ 4m, 가만히 있을 때 흔들림 ±5mm 정도
- 이 센서는 Hiwonder 제품이 아니라서 센서 설정 코드(드라이버)가 `mainboard.py` 안에 들어 있음. 전원은 MechDog 켜질 때 같이 켜지고, 설정은 켜질 때 한 번 자동으로 함

## 5. ToF 관련 설정값 (`mainboard.py` 위쪽)

| 설정 | 현재값 | 의미 |
|---|---|---|
| `TOF_BUS` | 1 | 뒤 센서를 먼저 찾을 통로 |
| `REAR_STOP_MM` | 200 | 뒤 장애물 멈춤 거리 |
| `REAR_STOP_ALL` | False | True면 앞으로 걸을 때도 뒤 장애물에 멈춤 |
| `FOLLOW_NEAR_MM` | 500 | 이 거리 이내면 원래 보폭 |
| `FOLLOW_FAR_MM` | 1200 | 이 거리면 최소 보폭 |
| `LOST_MM` | 1500 | 이보다 멀면 사람 놓침 |
| `RHYTHM_STRIDE_MIN` | 10 | 최소 보폭 |
| `LOST_CONFIRM_MS` | 1000 | 이만큼 놓치면 멈춤 |
| `FOUND_CONFIRM_MS` | 700 | 이만큼 잡히면 다시 걷기 |
| `LOST_END_MS` | 10000 | 이만큼 놓치면 리듬 큐잉 종료 |
| `BEAT_WHILE_WAITING` | True | 기다리는 동안에도 박수 소리 유지 |
| `DEBUG_REAR` | True | 뒤 거리 출력 (테스트 끝나면 False로) |

`DEBUG_REAR = True`일 때 출력 예: `rear: 245 raw: 243 age: 80 blocked: False dir: 0`
(rear = 판단에 쓰는 거리, raw = 마지막 측정값, age = 마지막 측정 후 시간, blocked = 뒤 막힘 여부, dir = 앱 걷기 방향 6~8이 뒤로)
