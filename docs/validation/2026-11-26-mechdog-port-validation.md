# MechDog 포트별 전압 측정 및 GPIO 검증

- 측정일: 2026-11-26
- 측정자: B 담당자
- 측정 장비: GN-5100 디지털 멀티미터
- 사용 프로그램: Thonny (MicroPython)

## 1. 포트별 전압 측정 결과

### 내부 포트

| 핀 | 측정 전압 | 추정 역할 |
|---|---|---|
| 1 | 5.08V | VCC 후보 |
| 2 | 측정 기준 | GND 후보 |
| 3 | 3.62V | 미확인 |
| 4 | 3.62V | 미확인 |

### Port 2

| 핀 | 측정 전압 | 추정 역할 |
|---|---|---|
| 1 | 3.62V | 신호 |
| 2 | 3.62V | 신호 |
| 3 | 측정 기준 | GND 후보 |

※ SDA, SCL 순서는 추가 확인 필요.

### Port 3

| 핀 | 측정 전압 | 역할 |
|---|---|---|
| 1 | 50~200mV 변동 | GPIO32 |
| 2 | 50~200mV 변동 | GPIO33 |
| 3 | 측정 기준 | GND 후보 |
| 4 | 5.08V | VCC 후보 |

※ GPIO32, GPIO33은 아래 추가 시험을 통해 확인했다.

### 측정 참고사항

- 세 포트 모두 5.08V가 안정적으로 측정됐다.
- 내부 포트와 Port 2의 핀 배열이 서로 다르게 측정됐다.
- 핀 번호는 측정 당시 관찰 방향을 기준으로 임시 지정했다.
- 실제 배선 전 커넥터 방향 및 공식 핀맵 확인이 필요하다.
- 내부 포트는 정확한 용도와 사용 가능 여부 확인 전까지 연결하지 않는다.

## 2. Port 3 추가 검증

### 검증 목적

Port 3의 1번, 2번 핀에서 50~200mV 사이의
지속적인 전압 변동이 발생하여 GPIO 출력 제어가
정상적으로 가능한지 추가 시험을 진행했다.

### 검증 방법

PC와 MechDog를 USB로 연결하고 Thonny에서
GPIO32, GPIO33을 각각 LOW → HIGH → LOW로
변경하면서 멀티미터로 전압을 측정했다.

외부 센서와 레이저는 연결하지 않은 상태에서 시험했다.

### 검증 결과

| 항목 | GPIO32 (1번 핀) | GPIO33 (2번 핀) |
|---|---|---|
| 초기 전압 | 50~200mV 변동 | 50~200mV 변동 |
| LOW | 0V | 0V |
| HIGH | 3.31V | 3.35V |
| LOW 복귀 | 0V | 0V |
| 검증 결과 | 정상 | 정상 |

두 GPIO 모두 무부하 상태에서 정상적으로
디지털 출력 제어가 가능한 것을 확인했다.

초기 전압 변동의 정확한 원인은 확인하지 않았다.

### 테스트 코드

GPIO32 테스트 예시:

```python
from machine import Pin

gpio32 = Pin(32, Pin.OUT, value=0)
gpio32.value(1)
gpio32.value(0)
```

GPIO33 테스트 예시:

```python
gpio33 = Pin(33, Pin.OUT, value=0)
gpio33.value(1)
gpio33.value(0)
```

각 명령어를 한 줄씩 실행하면서 전압을 측정했다.

재시험 시 외부 모듈을 분리하고 해당 GPIO를 사용하는
다른 프로그램이 실행 중이지 않은지 확인해야 한다.

기존 main.py, boot.py 및 펌웨어는 수정하지 않았다.

## 4. 추가 확인 필요 사항

- 커넥터 방향 및 공식 핀 번호
- 내부 포트의 정확한 용도
- VCC 및 GND 핀 최종 확인
- Port 2의 SDA, SCL 순서
- 포트별 허용 전류
- 외부 모듈 연결 시 출력 안정성
- 레이저 모듈과 GPIO의 호환성

※ GPIO의 HIGH 출력은 약 3.3V이며,
5V 전원 후보 핀과 구분해야 한다.

※ 무부하 출력 검증 결과만으로 외부 모듈의
직접 연결 가능 여부를 확정하지 않는다.
